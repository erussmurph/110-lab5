## Ticket <3>: <The lemon only lands in four spots>

### Actual cause
<!-- Which file and function was the bug in, and what was wrong with the code?
     Explain why that code produced the behavior described in the ticket. -->

**File / function:**
src/screens/GameScreen/GameScreenView.ts
**What was wrong:**
Stats "Best" parameter always displayed zero despite the actual best score.
### Fix
<!-- What did you change, and why does that change fix the problem? -->
changed Math.round() to be used only after the computation of the position was made by moving the parenthesis around the entire statement. 
Now Math.round() rounds the position instead of the Math.random() value from 0 to 1.
